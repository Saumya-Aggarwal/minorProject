- [high] (A. Kimi K2.6 API gotchas (OpenAI-compatible)) The base URL is https://api.moonshot.ai/v1. Thinking is ON by default and is turned off with extra_body={'thinking':{'type':'disabled'}}. # RECOMMENDATION
Verdict on Kimi: do not make Kimi the primary LLM for this WhatsApp shop assistant in Sept 2026. The cheap, fast Kimi the owner likely has in mind (K2 on Groq) was deprecated in March 2026, and Moonshot itself retired the K2 series (25 May) and K2.5 (31 Aug). What remains has three problems:

- **K2.6 is too slow and too expensive here.** It has strong vendor tool-use scores (tau2 about 96), but costs $0.95 input / $4.00 output per 1M tokens. That is about $22-36/month (₹2,000-3,200) for the stated workload, 5-10x the alternatives. Moonshot's own endpoint measured about 52 tok/s with about 2.8 s TTFT, so a tool round trip blows the 4-second target. It is also thinking-on by default, with fixed temperatures and reasoning_content echo rules the current assistant.py does not follow.
- **K3 is the wrong kind of model.** It costs $3 / $15 with reasoning that cannot be turned off; it is built for frontier coding and agents, at about $70-150+/month.
- **Kimi solves only vision, not voice.** Kimi accepts images (base64) and video but NOT audio, so voice notes need a separate speech-to-text service regardless. Every cheaper candidate also accepts images. Hindi and Hinglish quality is unpublished.

Kimi K2.6 through OpenRouter is at most an optional third-tier fallback for hard multi-step turns.

**Primary LLM: OpenAI gpt-6-luna.** Call it on Chat Completions with reasoning_effort='none', because function calling on Chat Completions only works at 'none'. Use strict JSON-schema tools and prompt caching.
- Price: $0.10 input / $0.01 cached / $0.50 output per 1M, about $2.5-4/month (≈₹210-360).
- It has image input and a 1M context, and it drops into the existing openai-SDK code with a base_url and model change.
- Caveat: it is 5 days old. Before switching, replay 100-200 logged Hinglish conversations from bot_replies and the eval phrasings through it, and measure p50/p95 latency.
- If it underperforms, step up to gpt-5.4-nano (about $5.5-9/month, established) or gpt-5.4-mini (about $20).

**Fallback LLM: Groq gpt-oss-120b on the paid Developer tier.** It costs $0.15 / $0.60, about $4-6/month if all traffic went there, runs at 474 tok/s with about 0.7 s TTFT, and the code already supports it. It is text-only.
- Using a different provider from the primary gives real redundancy.
- Stay off Groq's free tier for production: its 8K tokens/min and 200K tokens/day caps cause the 429s already seen.
- Budget alternatives worth an A/B test:
  - DeepSeek deepseek-flash: $0.15 / $0.003 / $0.60 off-peak, vision, about $3-6/month. It is China-hosted and prices double in Indian daytime peak windows.
  - Gemini 3.1 Flash-Lite: about $7/month. It takes audio and images natively, but has high TTFT with default thinking, and its free tier uses your data for training, so it is unsuitable for customer addresses.

**Speech-to-text: Sarvam Saaras v3/v4 as primary.** Use the REST API with mode='codemix' or 'translit' so Hinglish comes back usable for search. It costs ₹30/hour (about ₹75/month at 150 min), and the ₹100 signup credit covers about 200 minutes. It accepts the OGG/Opus files WhatsApp sends, has the best Indian-language word error rates in independent benchmarks, and claims under 250 ms median latency.
- Split notes longer than 30 s into chunks, or send them to the batch API.
- Fallback: Groq whisper-large-v3 with language='hi'. The free tier covers 8 audio-hours a day and paid is $0.111/hour, but it has Urdu-script and Devanagari quirks on Hinglish. Gemini Flash-Lite audio (about $0.001/min) is a second fallback.
- Pipeline: webhook, then fetch the media URL (expires after 5 minutes, needs a Bearer token), then STT, then feed the transcript into the normal text path. Echo the transcript back ("You said: …") so misheard words are visible.

**Image search: hybrid.**
1. At Shopify sync, embed every product photo with Marqo-FashionSigLIP. It is self-hosted on CPU, Apache-2.0, 0.2B parameters and 768 dimensions, stored in a pgvector vector(768) column with an HNSW index. SigLIP2-B/16 (Apache-2.0) is a close alternative. Never use plain CLIP: it scores 32-40% vs about 63% Recall@1 on the LookBench fashion benchmark.
2. For a customer photo or screenshot, run the image kNN in parallel with a vision-LLM call (GPT-6 Luna, or Gemini Flash-Lite as fallback). The LLM extracts category, gender, colour, print, fit and any visible text into structured filters plus a short English description.
3. Fuse the two ranked lists (reciprocal rank fusion), apply stock, size and gender filters in code, then let the assistant present the results.

This covers visual likeness (colour, print, cut) from embeddings and hard constraints and screenshot text from the LLM, at about $0 embedding cost plus under $0.01 per query. If you would rather not host models, the hosted alternatives are Voyage multimodal-3.5 (its free allowance covers this scale), Gemini Embedding 2 truncated to 768 or 1536 dims, or Cohere Embed v4. Avoid self-hosting jina-clip-v2: its CC BY-NC licence forbids commercial use.

**Text embeddings:** replace the English-only all-MiniLM-L6-v2.
- Self-hosted: EmbeddingGemma-300M (768 dims, Matryoshka down to 256, 100+ languages, runs on CPU).
- Hosted: text-embedding-3-small ($0.02/1M, shortened to 768 dims) or Voyage-4-lite ($0.02/1M with 200M free tokens).
- Either way, have the LLM write the search_products query in English. That makes Hinglish handling independent of the embedding model.

All of this fits the budget: a Hetzner CX33 (8 GB, about ₹870) plus LLM, STT and vision usage of about ₹400-700/month for the pilot brand, versus about ₹2,000-3,200 for Kimi K2.6 alone.

# OPEN QUESTIONS
- GPT-6 Luna came out on 22 Sep 2026. Nobody has published tool-calling (tau2/BFCL) or Hindi results for it, and its latency at reasoning_effort='none' has not been measured. It needs a live A/B test on the project's own logged Hinglish conversations before it replaces the current model.
- Kimi K2.6's Hindi and Hinglish quality is unpublished, and it is unclear how long Moonshot will keep K2.6 (K2.5 was retired after about 7 months).
- The tau2 scores come from aggregators that mix vendor-reported and independent runs and different domains (telecom, airline, retail), so they are not directly comparable.
- Data residency: Moonshot (Kimi) and DeepSeek are China-based, and Gemini's free tier may use prompts to improve Google's products. Check this against India's DPDP Act before sending customer names, phone numbers and addresses.
- Sarvam's official page says ₹30/hour, but one third-party site says ₹1.5/min. Confirm the actual billed rate in the Sarvam dashboard during the free-credit period.
- Gemini free-tier request limits (about 500/day for Flash-Lite) come from third-party guides; Google's docs only point to AI Studio. Groq Developer-tier limits were not retrieved either.
- How fast Marqo-FashionSigLIP and EmbeddingGemma embed on the actual VPS CPU, and how much RAM they take alongside Postgres, has not been measured.
- Rupee figures assume roughly ₹88 per US dollar.
